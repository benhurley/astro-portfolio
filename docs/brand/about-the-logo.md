# About the Ben Ventures logo

The logo is the HTML bold tag: `<b>`.

- **The b is for Ben.** `<b>` is also the tag for bold text.
- **The closing bracket doubles as a V.** Turn `>` a quarter turn and it's a v, so `b>` reads as BV — Ben Ventures. In the logo it stays on its side, pointing forward.
- **The colours are printing inks.** Magenta, black and cyan are three of the four standard CMYK process inks. The shapes come from code and the colours come from print — the two halves of the work: frontend development and design.

It's built on simple geometry: one stroke weight, a circular bowl, 90° brackets that match the height of the b's bowl, and a consistent gap between the brackets and the b.
